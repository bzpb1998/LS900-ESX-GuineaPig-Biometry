# v0.2.1 — V5 native Windows desktop

Download the ZIP below, fully extract it, and double-click `LS900 Biometry Analyzer.exe`. A native application window opens directly: no browser, installer, Python or Conda is required. Add raw ESX files, analyze locally and save a compact two-sheet Excel workbook.

- Original new icon, batch progress/cancellation, help and citation pages.
- Locked V5 parameters, shared Python API/CLI and native desktop analysis.
- Conda environment description, pinned dependencies, synthetic tests, license texts and source-access notices.
- Actual build-interpreter version recorded in RELEASE_MANIFEST.json. This corrects a metadata-only error in v0.2.0; the V5 model and calculations are unchanged.
- V4/v0.1.0 remains available. Private ESX, human records, manual reference tables/screenshots and vendor materials are not included.

V5's historical evaluation is retrospective, not a new blinded or fully animal-independent test. Research use only; not a clinical device or manufacturer-endorsed tool. Current unsigned Windows binaries may trigger an unknown-publisher warning; verify the source/checksum and follow institutional security policy, without disabling security controls.
