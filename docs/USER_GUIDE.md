# Windows V5 使用说明

软件 0.2.0，模型 V5。仅供豚鼠眼部生物测量研究，不是厂家官方软件，不得用于临床诊断。

## 下载与启动

从本项目 GitHub Releases 下载文件名含 `v0.2.0-V5-windows-x64.zip` 的包，而不是首页 Code → Download ZIP 或 Source code。完整解压，保留 `_internal` 和第三方许可证目录，双击 `LS900 Biometry Analyzer.exe`。无需安装 Python 或 Conda，直接出现独立窗口，不启动浏览器、不占用本地 HTTP 端口。

当前没有商业代码签名，Windows 可能显示未知发布者；不要关闭系统安全功能。请核对来源及随包 SHA-256，并依单位安全政策决定是否运行。

## 三步使用

1. 添加或拖入一批原始 `.esx` 文件，也可选择文件夹。文件夹只读取当前层级，不递归扫描。优先使用未手工调整的原始导出文件。
2. 点击“开始分析”。程序在本机读取信号，不上传数据，不改写原件；可取消批量任务。
3. 完成后点击“保存 Excel”，选择位置和文件名。需要复核/缺失原因见 Excel 的“说明”。关闭窗口即退出，没有需要额外关闭的浏览器服务。

没有 before/after 选项，文件名由使用者定义。程序不进行造模组间统计或眼轴增长比较。重复添加同一路径不会重复分析；不同文件即使动物编号相同，也保留为不同记录并加后缀，不静默合并。

## Excel 格式

仅“测量数据”和“说明”两张表。一只动物一行，OD 在左、OS 在右，中间两列空白，依次 AL、CCT、AD、LT、RT。AL/AD/LT 单位 mm，CCT/RT 单位 μm。晶体未通过门控时 AD/LT 留空，不猜测补值。AL 建议复核者保留数值并提示；自动质量标签不是准确概率。

AL 为角膜前表面至 ILM 的 EyeSuite 等效长度，不声称已由独立仪器标定为真实解剖距离。AD 从角膜后表面起算。RT 尚属探索性结果。异常解剖、含混视网膜边界和缺失晶体表面需要独立复核。

## 版本与验证

软件版本 0.2.0 与算法模型 V5 是两个不同的版本号。V5 参数与 2026-10-16 锁定版本一致；界面更新不重新训练。V4 软件 v0.1.0 仍保留在历史 Release。V5 现有评价是已揭盲历史资料上的回顾性评价，尚需新动物前瞻性验证。

历史 48 测试眼有 20 眼的同动物另一个时间点进入过训练，不能全部称为动物级独立。完整历史评价仍保留已知网脱眼；对正常眼的排除分析必须另行说明分母和排除原因。
