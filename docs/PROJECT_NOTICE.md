## 读取与输出

当前 Windows 桌面版读取使用者选择的 ESX，并在指定位置写入独立 Excel，不连接仪器、EyeSuite 或 MySQL 数据库，不修改原始 ESX，也不需要设备控制权限。没有必要把本工具安装到原始机器上。运行前应保存原始备份，避免覆盖其他研究结果。默认桌面版没有网络上传或后台 HTTP 服务。
