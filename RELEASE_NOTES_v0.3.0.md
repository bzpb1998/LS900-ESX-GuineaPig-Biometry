# OcularSpan v0.3.0

Independent ocular biometry research software. Formerly LS900 ESX Guinea Pig Biometry Analyzer.

## Windows download

Download **OcularSpan-v0.3.0-windows-x64.zip**, extract the complete folder and double-click **OcularSpan.exe**. No Python, Conda, browser service or installer is required. Keep _internal and license files. Verify the accompanying SHA-256 checksum.

## Changes

- Independent OcularSpan identity with the shorter Biometry Research subtitle and a new eye emblem.
- Compact native Windows workspace, batch file/folder input, progress/cancel, result saving, help and citation.
- Clear research-only, non-manufacturer, read-only-data, as-is and support documentation.
- New ocularspan / ocularspan-desktop commands; old Python imports and CLI names remain compatible.
- Same locked V5 model and measurement formulas. Two-sheet Excel with OD/OS separated by two empty columns is preserved.
- Preserve the exact frozen V5 JSON bytes in Git, including its original line endings, so source archives pass the same integrity check. Coefficients are unchanged.

OcularSpan is not designed, certified, or endorsed by Haag-Streit. LENSTAR LS 900 / EyeSuite names identify supported exports only. The desktop tool does not connect to or update the instrument's database. For research use only, not clinical diagnosis; provided as-is under the accompanying license.

The current V5 evaluation is retrospective and is not a new blinded validation. This release changes software identity and workflow, not biological accuracy. No raw ESX, patient/animal records, manual reference workbooks or manufacturer software are distributed.
